# 六套画风配方

配色数值来自对参考片关键帧的实测（320×180 降采样后 16 级量化取众数），可直接抄用，也可按品牌色换。

---

## 1. 红黄放射漫画

- 主色：正红底 `#D02020`、柠檬黄放射条 `#F0D040`、纯黑描边 `#101010`
- 构图：中心对称，12–16 条等腰放射线从中心外扩，视觉重心死钉在正中的人物/宝座
- 细节密度：极低（实测 detail 0.039），靠大色块和粗描边撑
- 用法：只用在开场 2–4 秒或章节转折的"印章式"定格
- 生图提示词骨架：`comic book poster, radial sunburst background, red and yellow, thick black outline, centered symmetrical composition, flat ink shading, no gradient`
- 实现：Qwen-Image 2.1 直出静态图 + 轻微缩放推镜即可，不需要动画

## 2. 像素横版

- 实测配色：砖墙棕 `#B86848` 16%、深蓝灰 `#384868` 7%、砖红 `#783838` 5%、浅橙 `#E8A878` 高光
- 特征：1px 硬边、无抗锯齿、砖墙半砖错缝、地板木条错位
- HUD：左上角关卡数、右上角标题条、中央血条（斜纹填充）、`∞` 表示无限
- 角色即概念：一个概念一个配色 + 一个配件（紫袍巫师 / 橙色头 / 蓝色机甲）
- 动效：角色原地小幅上下浮动，场景靠横移卷轴推进
- **必须用 `pixelfx`**：`node tools/render.mjs <category>/<name>` 出特效 contact sheet，先看再选；`node tools/list.mjs frost slash` 先搜现成效果
- 缩放：pixelfx 原生 320×180，输出 720p 时按 **4 倍最近邻整数放大**，不要双线性（会糊边）
- 精灵出图：`sprite-gen` 切透明循环帧，再拼回像素场景

## 3. 等距 3D 沙盘

- 实测配色：薄荷绿地面 `#A8C8A8` 26%、浅紫白楼体 `#D8D8E8` 9%、浅青屋顶 `#B8D8C8` 8%、深灰轨道 `#686878` 6%
- 视角：等距 45°，全片不换机位语言，只有平滑推拉与横移
- 光照：极浅环境光遮蔽，接近无影，干净的扁平 3D
- 世界语法：地面分区（虚线框）、滑轨传送带、立牌写规则、玻璃棚写"暂存"、红色箱写"重复"
- 镜头：单镜 15–40 秒，机位平移制造运动，不靠剪辑
- 生图提示词骨架：`isometric 3D miniature diorama, soft mint green ground, pastel purple and white buildings, thick dark grey conveyor tracks, matte clay material, soft ambient occlusion, no harsh shadows, clean flat lighting, 45 degree isometric view`
- 实现：Qwen-Image 2.1 出底图 → MiniMax H3 图生视频给 1.05 倍缓推 + 0.3 倍横移

## 4. 3D Q 版角色

- 实测配色：米灰 `#B8A898`、浅灰 `#A89898`、暖白 `#C8B8B8`，配一点深色服装
- 角色：大头 Q 版、圆眼镜、单一角色贯穿全片
- 动作：每个动作对应一句台词（推杯子、按按钮、翻文件、抬头）
- 背景：白色/米灰无边界空间，只留桌面、物件
- 实现：`character-anim`（静图 → H3 图生视频 → sprite-gen 循环帧）；同一角色要靠 RefMod 身份锁保持一致

## 5. 黑底白线手绘

- 实测：纯黑 `#080808` 占 63%，灰阶过渡到白
- 笔法：细白线 + 圆头火柴人，留出明显的"手绘抖动"
- 用法：全片唯一真正纯黑的一段，放在花哨之后做信息降噪
- 生图提示词骨架：`minimal white line drawing on pure black background, stick figure style, hand-drawn wobble, single line weight, generous negative space`
- 实现：SVG/Canvas 逐笔动画最干净，导出透明通道叠黑底；不必用视频模型

## 6. 深色科技流程图

- 深灰底 `#181820` + 细线框 + 单一强调色（青或橙）
- 节点命名用中文口语（"事件触发""Agent 内核""通知渠道"），不用术语缩写
- 动画：节点逐个亮起、连线逐条描出，严格跟随口播顺序
- 产品名用大字号压在图上，做一次视觉锤
- 实现：HTML + CSS animation 录屏，或 SVG stroke-dasharray 描线

## 通用层

- 字幕：白字 + 2px 黑描边 + 轻投影，底部 88% 高度居中，字号在 720p 下约 40–44px
- 场景内文字：跟着物体透视缩放，字号不小于字幕的 70%
- 转场：同画风内用位移/推进，换画风时用 0.2–0.3 秒硬切或闪白，不做花式转场
- 切点密度：全片平均 2 秒一刀；结构段 4 刀/30 秒，冲击段 20 刀/20 秒
