## 这是什么

一套「把抽象系统讲成动画」的方法与画风库。

解决的问题：**你的系统很好，但你讲的时候别人在刷手机。**

## 六种画风

| 画风 | 适合内容 |
|---|---|
| 像素横版关卡 | 流程步骤、状态流转 |
| 等距 3D 沙盘 | 空间结构、部署拓扑 |
| 3D Q 版角色 | 角色驱动的流程讲解 |
| 黑底白线手绘 | 概念解释、脑图 |
| 深色科技流程图 | 架构、数据流 |
| 漫画海报 | 单点概念、钩子 |

## 核心原则

1. **先有冲突，再讲概念**。没有「什么问题」，讲了也记不住。
2. **一镜一个信息点**。三个概念塞一个镜头，等于都没讲。
3. **画风要换**。连续同一种画风超过 20 秒，注意力会掉。

## 适用场景

- 产品发布视频
- 中台 / 架构介绍
- Agent 工作流说明
- 技术科普
- 内部培训片
